# Signal Processing — STM32G474CEU6

Прошивка обработки восьми источников импульсов для STM32CubeIDE.

- ADC1: каналы ch[0]–ch[3]; ADC2: ch[4]–ch[7].
- ADC3 и ADC4: измерение энергии двух каналов усилителя; ADC5 — резерв.
- Измерение длительности импульсов таймерами, сбор отсчётов через DMA.
- COMP1/COMP2: входы защиты variant B с внешним объединением сигналов.

## Текущая сохранённая версия

На макете подтверждена длительная работа измерений. Последняя правка сохраняет
события спада, прочитанные обработчиком DMA, для последующей обработки таймерами.
Восстановление измерений ch[1]/ch[2] после этой правки ещё требует подтверждения
на плате. Это исходная версия для отслеживания изменений, не проверенный релиз.

`current_mA` вычисляется из напряжения с коэффициентом 0.95 В/мА;
`voltage` содержит напряжение. В расчёте используется VREF = 3.3 В.

Остановка TIM20 по защите выполняется обработчиком прерывания;
наносекундная аппаратная остановка запуска АЦП не подтверждена.

## Работа с проектом

Импортировать существующий проект в STM32CubeIDE. Исходники находятся в `Core/`,
библиотеки ST — в `Drivers/`. Результаты сборки и локальные настройки отладки
не сохраняются в Git. Файл `.ioc` сохранён, но регенерация CubeMX может затронуть
ручные изменения: перед ней следует сохранить текущую версию.

Последующие изменения сохраняются отдельными коммитами с описанием исправления.
Теги релизов следует создавать после подтверждения работы соответствующей версии
на плате. Сборки и тесты запускаются только по отдельному запросу владельца.
